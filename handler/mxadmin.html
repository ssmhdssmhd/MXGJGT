M3U8 广告过滤（去插播）规则

按主机名前缀 / 正则匹配播放域名，命中后自动剔除插播广告片段；未命中则走自动模式（块分析 + 序列连贯性）。

系统设置 · 路径设置

调用路径即接口地址，客户端用它访问：http://<域名>/api/clean/?url=

可自定义多个路径（支持 http / https），任一命中即生效；未命中这些路径的其它请求统一返回 nginx 风格 404 伪装。

去插播地址格式：该路径/?type=m3u8&url=<播放地址>（由 /api/clean 返回 JSON 里的 qcb 字段给出）。
