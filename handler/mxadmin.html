广告过滤

统一管理全部去广告能力：插播片段级（M3U8 去插播）与画面内嵌级（遮罩贴片）。

M3U8 广告过滤（去插播）规则

按主机名前缀 / 正则匹配播放域名，命中后自动剔除插播广告片段；未命中则走自动模式（块分析 + 序列连贯性）。

画面遮罩（内嵌广告 / 贴片）规则

针对「广告文字 / 台标 / 二维码烧进画面像素」的内嵌广告：命中播放域名后，服务端在 /api/clean 响应里以 ad 字段下发遮罩区域，播放器按相对坐标叠加遮罩（零转码、零带宽、秒级生效）。

新增规则时可直接粘贴链接自动识别：自动解析匹配域名、推荐绑定资源站（绑定后调用该资源站即自动套用，无需再逐个配域名）并给出候选遮罩区域。

系统设置 · 路径设置

调用路径即接口地址，客户端用它访问：http://<域名>/api/clean/?url=

可自定义多个路径（支持 http / https），任一命中即生效；未命中这些路径的其它请求统一返回 nginx 风格 404 伪装。

去插播地址格式：该路径/?type=m3u8&url=<播放地址>（由 /api/clean 返回 JSON 里的 qcb 字段给出）。
